# Aranea-ads

โฆษณาที่แอป Aranea แสดง แก้ไฟล์ [`ads.json`](ads.json) แล้วแอปจะเปลี่ยนตามเอง ไม่ต้องลงแอปใหม่

- แอปดึงไฟล์นี้ตอนเปิดหน้าหลัก (ไม่บ่อยกว่าทุก 15 นาที) ถ้าออฟไลน์จะใช้ชุดล่าสุดที่เคยดึงได้
- หลังแก้อาจใช้เวลาถึงประมาณ 5 นาทีกว่าจะเห็นในแอป (GitHub เก็บแคชไฟล์ไว้)
- โฆษณาจะขึ้นเฉพาะชั้นหนังสือหลัก ไม่ขึ้นในโฟลเดอร์ ตอนกรอง หรือตอนค้นหา

## วิธีแก้

1. เปิด [`ads.json`](ads.json) บนเว็บ GitHub แล้วกดรูปดินสอ (Edit)
2. แก้ข้อความตามตัวอย่างข้างล่าง
3. กด **Commit changes**

ถ้าไฟล์เขียนผิดรูปแบบ (เช่นลืมจุลภาค) แอปจะไม่ใช้ไฟล์ใหม่ และแสดงชุดเดิมต่อไป เช็คได้ที่ [jsonlint.com](https://jsonlint.com) ก่อน commit

## รูปแบบไฟล์

```json
{
  "banners": [ ...แบนเนอร์บนสุดของหน้าหลัก (แสดงทีละอัน ตัวแรกที่อยู่ในช่วงวันที่)... ],
  "shelf":   [ ...การ์ดที่แทรกอยู่ในชั้นหนังสือ (แสดงทุกอันที่อยู่ในช่วงวันที่)... ]
}
```

แต่ละอันมีช่องเหล่านี้ (มีแค่ `id` กับ `title` ที่ต้องใส่ ที่เหลือเว้นได้)

| ช่อง | ความหมาย | ตัวอย่าง |
|---|---|---|
| `id` | ชื่อเฉพาะของโฆษณา **ห้ามซ้ำ** ถ้าผู้ใช้กดปิดอันไหน อันที่มี `id` นั้นจะไม่ขึ้นอีก ทำโฆษณาใหม่ให้ใช้ `id` ใหม่ | `"promo-2026-12"` |
| `title` | หัวข้อ | `"ลด 20% ทั้งร้าน"` |
| `subtitle` | ข้อความรอง | `"ถึงสิ้นเดือนนี้เท่านั้น"` |
| `image` | ที่อยู่รูป (อัปโหลดรูปไว้ในโฟลเดอร์ `images/` แล้วใช้ที่อยู่แบบตัวอย่าง) | `"https://raw.githubusercontent.com/k-zencool/Aranea-ads/main/images/promo.jpg"` |
| `link` | เว็บที่จะเปิดเมื่อแตะ | `"https://example.com"` |
| `start` | วันเริ่มแสดง (ปี ค.ศ.-เดือน-วัน) | `"2026-12-01"` |
| `end` | วันสุดท้ายที่แสดง (แสดงถึงสิ้นวันนั้น) | `"2026-12-31"` |
| `background` | สีพื้น | `"#6E7BFF"` |
| `textColor` | สีตัวอักษรของแบนเนอร์ | `"#FFFFFF"` |
| `position` | เฉพาะการ์ดในชั้น: อยู่หลังสมุดเล่มที่เท่าไร (ไม่ใส่ = 3) | `2` |

## ขนาดรูปที่แนะนำ

- แบนเนอร์: รูปแนวนอน 4:3 เช่น 448 × 336
- การ์ดในชั้น: รูปแนวตั้ง 3:4 เช่น 600 × 800 (เท่าปกสมุด)

## ไม่ต้องการโฆษณาชั่วคราว

ใส่ list ว่าง:

```json
{ "banners": [], "shelf": [] }
```
